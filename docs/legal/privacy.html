Privacy Policy

Last updated: 2026-07-25

This policy describes how Pokered Save Editor 2 — a free, open-source desktop application for editing Pokémon Red & Blue save files — and this documentation website handle information. It is written to match what the software and site actually do; it is not boilerplate.

The desktop application

The editor runs entirely on your own computer. It has no account, no sign-in, and no server. When you open a .sav file it is read, edited, and written back on your device only. Nothing about your save file, your edits, or your usage is transmitted anywhere, collected, or stored by us — there is nowhere for it to go, because the application talks to no server of ours. It contains no analytics, telemetry, tracking, or advertising.

This documentation website

These docs are a static site hosted on GitHub Pages. As the host, GitHub may log standard request metadata (such as IP address and user agent) as a processor; see GitHub's own privacy documentation. We add no analytics, tracking pixels, or advertising to the site. Fonts are self-hosted from this same origin — no request is made to Google Fonts or any third-party font CDN, so loading a page exposes your IP to no third party beyond the host.

Device-only local storage (this website)

To remember your reading choices and a small reading-engagement counter, the site keeps a few values in your browser's local storage. This is not a cookie, stays on your device, and is never sent to any server:

  • Reader preferences — your chosen theme, accent, and text size.
  • Fairy Fox coins — a local coin balance and the record of which documentation pages you have opened today (used only to award the cosmetic counter). Coins have no monetary value; see the Terms and the shared explainer at fairyfox.io/legal/coins/.

You can clear these at any time: use the reader panel's Reset control and the coins panel's Clear my data link, or clear site data in your browser. See the Cookies Policy for the cookies-vs-local-storage detail.

Analytics & tracking

We use no analytics, no tracking pixels, and no advertising, in either the app or the site.

Children

This project is not directed at children under 13 and contains no adult content.
